


# CommonwealthMP (CMP)

CommonwealthMP is a co-op multiplayer mod for Fallout 4.

> **Heads up:** CMP is being fully reworked around a server-side design, where the server holds the game state instead of relying on the players' games to do the work. The old research code that used to live here has been removed. It is still in this repository's history if you want to look at it, but it is not maintained.
>
> The new code will be published here once it is cleaned up and stable enough to share. Thank you for your patience :)

## What CMP is aiming for

A fun and stable co-op Fallout 4 experience with the features a co-op game needs, such as:

- Reviving downed teammates
- Fast travel to teammates
- Chat and emotes
- Per-player loot, shared quests and rewards
- In-sync NPCs and smooth movement
- Building settlements together
